# stock-daily-briefing

장 마감 브리핑 웹페이지를 매일 자동으로 만드는 프로젝트입니다. 현재는 코스피·코스닥을 다룹니다.
장 마감 후부터 다음날 개장 전까지 아무 때나 열어보도록 만들었습니다.

> 자동으로 만들어진 참고 자료이며 투자 권유가 아닙니다.
> 종목 선정은 과거 가격과 거래량에서 계산한 기계적 조건에 따른 것으로 수익을 보장하지 않습니다.

## 화면 구성

1. **코스피·코스닥 지수** — 종가, 등락, 최근 추이
2. **오늘의 시장** — 지수 요약과 상승·하락 종목 수
3. **주요 뉴스**
4. **주요 종목** — 시장(코스피/코스닥) × 기준(거래대금 상위/등락률 상위)
5. **내일 주목할 종목** — 조건을 충족한 종목과 그 근거
6. **검색** — 종목명이나 코드로 즉시 검색, 누르면 차트·회사 정보·뉴스

## 데이터 출처

| 항목 | 출처 | 키 |
|---|---|---|
| 전 종목 시세·시가총액 | 네이버 금융 | 불필요 |
| 종목별 일별 시세(차트) | 네이버 금융 | 불필요 |
| 코스피·코스닥 지수 | 네이버 금융 | 불필요 |
| 뉴스 | 네이버 검색 API (실패 시 구글 뉴스 RSS) | `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` |
| 회사 개요(업종·설립연도·대표자) | DART 전자공시 | `DART_API_KEY` |

키는 GitHub Secrets에 넣습니다. 없어도 해당 항목만 빠지고 나머지는 정상 동작합니다.

**주의** — KRX 공식 API는 로그인을 요구하도록 바뀌어 쓰지 않습니다. 네이버 금융은 공식
API가 아니라 언제든 구조가 바뀔 수 있어, 수집부(`app/naver.py`)만 고치면 되도록 분리했습니다.

## 실행

```bash
pip install -r requirements.txt
python build.py          # dist/index.html 생성
```

자동 실행은 평일 16:40 KST(`.github/workflows/daily.yml`)이며,
Actions 탭에서 수동 실행 시 차트를 준비할 종목 수를 지정할 수 있습니다.

## 설정 (환경변수)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `CHART_LIMIT` | 800 | 차트를 준비할 종목 수 (거래대금 상위순) |
| `CHART_DAYS` | 60 | 차트에 담을 거래일 수 |
| `TOP_N` | 10 | 목록에 보여줄 종목 수 |
| `WATCH_N` | 4 | 내일 주목할 종목 수 |
| `MIN_VALUE` | 10억 | 당일 거래대금 하한(원) |
| `MIN_MARKET_CAP` | 500억 | 시가총액 하한(원) |

## 구성

```
build.py              수집 → 계산 → 페이지 생성
app/naver.py          네이버 금융 수집 (시세·지수·일별시세)
app/news.py           뉴스 수집 (네이버 → 구글 RSS 순으로 시도)
app/dart.py           DART 기업개황 + 캐시
app/indicators.py     이동평균·RSI·거래대금 급증·신고가
app/picks.py          내일 주목할 종목 선정과 근거 생성
app/template.html     화면 (데이터는 빌드 시 주입)
```
